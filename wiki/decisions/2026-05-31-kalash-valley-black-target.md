# Kalash Valley Black Target — Black-Line Introgression

The breeding target is upgraded from "stabilize a very dark purple SBxBS01 line" to "use the best purple/fruity Serious Black expression as one parent and introgress a true black landrace source." Kalash Valley Black is now the priority outside genetic target.

## Source candidate

Kalash Valley Black is listed by Mandala Seeds as an Indian Landrace Exchange strain made available through Ace Seeds collaboration. The product listing describes it as:

- genetics: Kalash, Pakistan
- type: indica
- regular seed format, 5- or 10-seed packs
- sweet, berry, floral aroma
- tall/lanky plant habit
- deep black color during maturation
- high resistance to mold, heat, cold spells, temperature swings, and drought

Mandala's public shipping page currently lists USA shipping with exclusions, but the operational constraint for this project is: **do not assume we can source Kalash Valley Black before September 2026.** The user reports Mandala's United States shipping is paused through September. Recheck the product page, shipping page, and checkout availability before any purchase attempt.

## Decision

Treat Kalash Valley Black as a major breeding target and likely parent for the eventual black line.

The near-term SBxBS01 work still matters:

- identify the best purple Serious Black / SBxBS01 female, especially if A or D finishes with exceptional color, fruit, and structure
- preserve that female by clone if possible
- bank useful SBxBS01 pollen if Track A males pass evaluation
- keep the current purple-line notes as the first parent-selection layer, not the final project endpoint

The likely cross direction is:

```text
elite purple/fruity SBxBS01 female x Kalash Valley Black male
or
Kalash Valley Black female x selected SBxBS01 male
```

The first direction is currently preferred if the current grow produces a clearly superior A/D-style female clone, because it preserves the known purple/fruity Serious Black expression as the seed mother and uses Kalash Valley Black as the black-color introgression donor.

## Rationale

The original "black cannabis" goal was treated as likely unrealistic from the starting SBxBS01 pool alone. Kalash Valley Black changes that assumption because it is explicitly sold as a black strain from a landrace/heirloom source. It may provide stronger black-color alleles than selecting only within the current purple pool.

The tradeoff is that Kalash Valley Black is an indica landrace while the current target preferred a sativa-leaning, trellis-friendly structure. That means black color becomes the primary introgression trait, while structure, fruit terpenes, manageable flower time, and hermaphrodite resistance must be recovered through F2/F3+ selection.

## Consequences

- The program should not spend the whole next cycle chasing a different BS line unless it directly helps parent selection before Kalash Valley Black is available.
- The September 2026 sourcing checkpoint is now a timeline dependency.
- Once Kalash Valley Black is sourced, run it as a serious parent population, not as a curiosity side plant.
- Keep separate family lots from any SBxBS01 x Kalash Valley Black crosses. Do not bulk pollen unless intentionally creating a broad base population.
- The eventual project page should likely be named around the black-line goal rather than the old purple-line goal.
